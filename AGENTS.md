# Datalk

Datalk 是一个本地运行的自然语言问数项目。前端使用 Vue 3，后端使用 FastAPI、LangGraph 和 DuckDB。

## Agent skills

### Issue tracker

Issues and PRDs for this repo live in GitHub Issues at `Anthony-0721/Datalk`. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical five triage labels are in use, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one root `CONTEXT.md` plus `docs/adr/`. See `docs/agents/domain.md`.
